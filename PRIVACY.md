# BusyMouse privacy policy

_Last updated: 9 November 2026_

BusyMouse does not collect, store or share any personal information.

- **No data leaves your PC.** BusyMouse makes no network connections: no telemetry, analytics, ads, accounts or
  update checks.
- **Settings stay on your PC.** Your choices (nudge style, interval, distance, theme and so on) are saved in a
  settings file in your user profile (`%LOCALAPPDATA%\BusyMouse\settings.json`, or the app's own storage when
  installed from the Microsoft Store). Uninstalling BusyMouse, or deleting that file, removes them.
- **Pointer and lock state are used only on your PC.** BusyMouse moves the pointer, checks whether you've used the
  mouse recently so it can skip a nudge, and, if you turn it on, notices when the PC is locked. None of this is
  recorded or sent anywhere.

The "no runtime" downloads from GitHub include a small launcher that, only if the .NET Runtime is missing and you
agree, downloads it from Microsoft (`aka.ms` / `dotnet.microsoft.com`). Microsoft's privacy statement applies to that
download. The Microsoft Store version doesn't need it.

Questions: open an issue at https://github.com/bdislamazharul/busymouse/issues.
